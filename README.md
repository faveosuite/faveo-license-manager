<h1>Agora License Manager</h1> 


<h3>About Agora Licensing</h3>

Agora Licensing is Managing Licenses for Agora Invoicing and Faveo Helpdesk.

Agora is designed & developed by <a href="http://www.ladybirdweb.com/" target="_blank">Ladybird Web Solution Pvt Ltd</a>, and launched in Oct 2021.

<h4>To run Agora License Manager your host just needs a couple of things:</h4>
<ul>
<li> Web Server: Apache or IIS or Nginx</li>
<li> PHP Version: 8.1+</li>
<li> Laravek Framework: 9.0+</li>
<li> PHP Extensions: Mcrypt, OpenSSL, Mbstring, Tokenizer</li>
<li> Database: MySQL(8.0+) or Postgres or SQLite or SQL Server</li>
<li> Web Server Extension: Pretty URLs or Search Engine Friendly URL's have to be enabled in your web server configuration</li>
</ul>

<h4>Agora License Manager Features</h4>
<ul>
	<li>One installation for unlimited products, clients and licenses</li>
	<li>Lifetime, time-expiring and feature-limited licenses</li>
	<li>IP address and (sub.)domain based restrictions</li>
	<li>Blocked installation for users without active licenses</li>
	<li>Direct License Monitoring</li>
	<li>Guaranteed protection from software piracy</li>
</ul>
